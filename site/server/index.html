JsMessenger

Хотите, чтобы переписка и звонки жили на вашем сервере, а не у кого-то ещё? Я поставлю всё нужное одной командой — минут за десять.

Что окажется на сервере:

  • Synapse и PostgreSQL — сервер Matrix: чаты, файлы, шифрование, связь с другими серверами;
  • LiveKit — звонки, видео и показ экрана в JsMessenger, Element X и Element Call;
  • Jitsi Meet — видеовстречи по ссылке, даже для тех, у кого нет Matrix;
  • Caddy — HTTPS: сертификаты Let's Encrypt он получает и продлевает сам.

Понадобится сервер на Ubuntu или Debian и домен. Добавьте A-записи на IP сервера:

example.ruадреса вида @имя:example.ru
matrix.example.ruсервер Matrix
rtc.example.ruзвонки
meet.example.ruJitsi Meet

2 ядра и 2 ГБ памяти без Jitsi, 4 ГБ — с Jitsi. Порты 80 и 443 должны быть свободны.

А дальше — три строки:

git clone https://github.com/JedySan/JsMessenger-server.git /opt/jsm-server
cd /opt/jsm-server
sudo ./install.sh

Я спрошу домен и почту, проверю DNS и порты, сам придумаю пароли, запущу всё и заведу администратора. В конце проверю снаружи, что HTTPS, Matrix, звонки и Jitsi отвечают.
